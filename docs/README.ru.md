## О проекте

**BP Diary V18 / 5.8.1** — Android-приложение для ведения дневника артериального давления, повторных замеров, анализа динамики, напоминаний, резервного копирования и формирования отчётов для врача.

Приложение построено как local-first: записи дневника и профиль остаются на устройстве, пока пользователь сам не экспортирует или не отправит данные.

## Основные возможности

### 🩺 Замеры

- до 3 повторных замеров в одном сеансе;
- ввод САД / ДАД / пульса;
- поддержка левой и правой руки;
- проверка новых и редактируемых значений до сохранения;
- явно некорректный ввод блокируется;
- сохранён отдельный предупреждающий сценарий для экстремальных, но допустимых значений;
- существующие исторические записи не переписываются новой валидацией.

### 📊 Архив и аналитика

- архив сеансов;
- быстрый поиск;
- фильтры по периоду;
- сортировка по дате;
- редактирование и удаление;
- графики и сводные показатели;
- светлая и тёмная темы.

### ⏰ Напоминания

Можно настроить:

- до 3 времён измерения в день;
- 1 / 2 / 3 сигнала;
- интервал повтора 5 / 10 / 15 / 30 минут;
- 3 системных звука Android;
- вибрацию;
- тест звука;
- действие **«Измерено»**;
- действие **«Напомнить позже»**.

Расписание восстанавливается после перезагрузки устройства, а также после изменения времени или часового пояса.

### 📄 Отчёт врачу

Отчёт формируется в **A4 landscape**, в стиле ПК-версии.

Поддерживаются:

- выбор периода;
- предварительный просмотр;
- сводные показатели;
- профиль и контекст;
- полная таблица измерений;
- Print;
- Save PDF;
- Share PDF.

Medical/core-расчёты отчёта не меняются мобильным экспортом.

### 🔐 Приватность

V18 включает:

- системный Android App Lock;
- biometric/device credential authentication;
- повторную блокировку после 10 секунд в фоне;
- блокировку сразу после физической блокировки экрана;
- Screen Privacy через Android `FLAG_SECURE`;
- скрытие содержимого в Recent Apps при включённой защите.

### 💾 Резервные копии

Доступны два режима:

**Обычный Full Backup**
- JSON;
- нужен для совместимости и обычного экспорта.

**Защищённый Full Backup**
- пароль не сохраняется приложением;
- PBKDF2-SHA-256;
- 310 000 итераций;
- случайная 16-байтовая соль;
- AES-GCM-256;
- случайный 12-байтовый IV;
- неверный пароль или повреждение файла отклоняются до изменения текущих данных.

Если пароль от защищённого бэкапа утерян, BP Diary не может его восстановить.

## 📦 Установка

Официальный stable release:

**V18 / 5.8.1**

[Открыть официальный GitHub Release](https://github.com/TokhirjonYuldoshev/BP-Diary-Android/releases/tag/v5.8.1)

Файл:

```text
BP-Diary-5.8.1-V18.apk
```

SHA-256:

```text
38b1e92307df61915ff85edc8e447688f4f36010ec39c6e01178a9f5796b1301
```

Проверка в Linux/macOS:

```bash
sha256sum BP-Diary-5.8.1-V18.apk
```

V18 сохраняет Package ID, но использует новую приватную подпись относительно V17. Для перехода с V17: создайте и проверьте Full Backup, удалите V17, установите V18 и восстановите данные. Для обновлений внутри V18 5.8.x сначала создайте и проверьте Full Backup. На одном реальном устройстве официальное обновление 5.8.0 → 5.8.1 без uninstall было отклонено Android; расследование ведётся в Issue #18.

Перед uninstall или переносом на другое устройство рекомендуется сделать Full Backup.

## 🧱 Архитектура проекта

Ключевые файлы:

```text

assets/mobile-modern.css
scripts/prepare-web.mjs
scripts/patch-android.mjs
scripts/regression.mjs
tests/ui-v18.spec.mjs
```

Разделение ответственности:

- `source/index.html` — основное приложение и core;
- `assets/mobile-modern.*` — мобильный UI/UX;
- `scripts/prepare-web.mjs` — подготовка offline web bundle;
- `scripts/patch-android.mjs` — Android-native bridge;
- `scripts/regression.mjs` — статический regression;
- `tests/ui-v18.spec.mjs` — Playwright UI regression.

Подробнее: [ARCHITECTURE.md](../ARCHITECTURE.md).

## 🛠️ Локальная сборка

Требования:

- Node.js 22;
- Java 21;
- Android SDK;
- npm.

Базовая последовательность:

```bash
npm ci
npm run prepare:web
npm run qa
npx cap add android
node scripts/patch-android.mjs
npm run cap:sync
```

Сгенерированные `www/`, `android/` и `node_modules/` не являются основными исходниками и не хранятся в Git.

## ✅ QA и защищённый main

Ветка `main` защищена ruleset.

Перед попаданием commit в `main` обязательны:

- `build-apk`;
- `mobile-ui`.

Оба check запускаются GitHub Actions на рабочих ветках, чтобы commit мог быть проверен до интеграции в `main`.

Release дополнительно защищён `release-request.json`. В обычном состоянии:

```json
{
  "publish": false
}
```

Публикация выполняется только отдельным намеренным release-коммитом.

### ⚠️ Известная проблема обновления

Официальные V18 5.8.0 и 5.8.1 имеют одинаковый package ID и production-сертификат, а versionCode повышен с 181 до 182. Несмотря на это, на одном реальном устройстве установка 5.8.1 поверх существующей V18 не прошла.

Перед uninstall/reinstall обязательно создайте и проверьте Full Backup. Не устанавливайте CI/debug-сборки на основной телефон. Подробности и команды диагностики: [KNOWN_ISSUES.md](../KNOWN_ISSUES.md) и [Issue #18](https://github.com/TokhirjonYuldoshev/BP-Diary-Android/issues/18).
